# AppleMe – بطاقات Overlay لصندوق أندرويد TV

تطبيق يعرض بطاقات (طقس، مواقيت الصلاة، مباريات كووورة، الرام، المعالج، الساعة) **فوق أي تطبيق** بضغطة مطوّلة على مفتاح تختاره من الريموت. يعمل في الخلفية على **أندرويد 9 → 14** (minSdk 28 / targetSdk 34).

> ⚠️ لم يُبنَ المشروع ولم يُجرَّب على جهاز حقيقي قبل التسليم (لا يوجد Android SDK في بيئة الإنشاء). أول بناء على GitHub قد يحتاج تعديلاً بسيطاً — لو فشل أرسل سجل Actions.

## كيف يعمل
- **KeyService** (خدمة إتاحة): تستمع لمفاتيح الريموت وتُظهر/تُخفي الـ overlay عند الضغط المطوّل. الـ overlay نافذة `TYPE_ACCESSIBILITY_OVERLAY` فيها WebView شفاف. الخدمة يشغّلها النظام تلقائياً بعد إعادة التشغيل، وتُعاد بناء الـ WebView تلقائياً لو أغلقه النظام لنقص الذاكرة.
- **assets/index.html**: واجهة البطاقات. **assets/koora.js**: يستخرج مباريات اليوم من كووورة.
- **Bridge / SysInfo**: رام ومعالج وحرارة حقيقية، Clear all، فتح الإعدادات والمساعد الصوتي، وطلبات الشبكة (طقس/بحث/IP).

## الطقس
- Open-Meteo للتوقعات وجودة الهواء والبحث (كل مدن العالم).
- **تلقائي بالـ IP**: geojs.io ← ipwho.is ← ipapi.co.
- **بحث يدوي**: الإعدادات (أيقونة الترس في بطاقة الطقس) ← Search بلوحة مفاتيح على الشاشة (إنجليزي/عربي) تعمل بالريموت.

## مباريات كووورة
عند فتح البطاقة (وكل 5 دقائق في الخلفية) يفتح التطبيق صفحة «مباريات اليوم» في WebView مخفي ويستخرج البطولات والمباريات والقنوات. إن فشل جرّب جلب HTML مباشرة، وإن فشل يعرض نسخة محفوظة مع تنبيه. إعدادات: اختيار البطولات (الافتراضي: الأشهر فقط)، إزاحة الوقت بالساعات إن اختلف التوقيت، وجرس تنبيه لكل مباراة.
> بيانات كووورة لا تتوفر منهم عبر API رسمي؛ الاستخراج يعتمد على شكل صفحتهم وقد يتعطل إن غيّروه. راجع شروط استخدام الموقع قبل أي توزيع.

## البناء على GitHub (بدون Android Studio)
1. أنشئ مستودعاً جديداً على github.com.
2. ارفع محتويات هذا المجلد كلها (الأفضل git، وتأكد أن `.github/workflows` اترفع):
   ```bash
   cd AppleMe   # المجلد بعد فك الـ zip
   git init && git add . && git commit -m "AppleMe"
   git branch -M main
   git remote add origin https://github.com/<اسمك>/AppleMe.git
   git push -u origin main
   ```
3. تبويب **Actions** ← **Build APK** (يعمل تلقائياً، أو **Run workflow**).
4. بعد 3–6 دقائق افتح التشغيل الناجح ← **Artifacts** ← حمّل `AppleMe-debug-apk`.
(محلياً: افتح المجلد في Android Studio ← Build APK، أو `gradle assembleDebug` مع JDK 17 وGradle 8.9.)

## التثبيت والتفعيل
```bash
adb connect <IP الصندوق>:5555
adb install -r app-debug.apk
```
1. افتح **AppleMe** ← **Enable the service** ← فعّل *AppleMe overlay key*.
   - أندرويد 13+: لو الزر رمادي: إعدادات ▸ التطبيقات ▸ AppleMe ▸ ⋮ ▸ **Allow restricted settings**.
   - أو عبر adb:
     ```bash
     adb shell settings put secure enabled_accessibility_services com.tvoshome.app/com.tvoshome.app.KeyService
     adb shell settings put secure accessibility_enabled 1
     ```
2. (اختياري) **Allow usage access** أو `adb shell appops set com.tvoshome.app GET_USAGE_STATS allow`
3. **Keep alive**: استثناء التطبيق من توفير البطارية، وإن كان في صندوقك قائمة «التشغيل التلقائي/Autostart» فاسمح للتطبيق.
4. **Record the toggle key** ثم اضغط المفتاح من الريموت (أو من إعدادات الـ overlay).

## الاستخدام
- ضغطة مطوّلة على مفتاحك = إظهار/إخفاء. الأسهم تنقّل، OK يفتح، OK مطوّلاً على بطاقة = تحريكها، Back يغلق ثم يخفي.
- إشعارات الصلاة والمباريات تظهر كبطاقة خفيفة 9 ثوانٍ حتى والـ overlay مخفي.

## حدود يجب معرفتها
- **HOME**: أندرويد لا يسمح للتطبيقات باعتراضه؛ استخدم MENU أو مفتاحاً آخر.
- **الحرارة/المعالج**: يجرّب بالترتيب: ملف مخصص ← `thermal_zone*` و`hwmon` ← مسح شامل لـ `/sys/devices` (يلتقط حساسات الشرائح غير القياسية مثل بعض Goke) ← `dumpsys thermalservice`. نافذة CPU تعرض قائمة **THERMAL SENSORS** بما وُجد. لم أستطع تجربة Goke فعلياً ولم أجد مسارات موثّقة له، فإن ظهر N/A:
  - `adb shell pm grant com.tvoshome.app android.permission.DUMP` (يفعّل مصدر dumpsys).
  - أو حدّد الملف يدوياً (بعد معرفته بـ `adb shell find /sys -name 'temp*'`): `adb shell am start -n com.tvoshome.app/.MainActivity --es thermal_path /sys/.../temp`
  - الاستخدام: من `/proc/stat` ثم تقدير من التردد ثم `loadavg`.
- **الرام لكل تطبيق**: يخفيه أندرويد الحديث فقد يظهر «—». Clear all يغلق التطبيقات الخلفية فقط.
- **الصناديق القديمة**: WebView قديم قد يُظهر الشكل أبسط (بدون blur)؛ حدّث «Android System WebView» إن أمكن.
- **الدقة**: مواقيت الصلاة تُحسب محلياً وقد تختلف دقيقة عن التقويم الرسمي (يوجد تعديل بالدقائق).

## ما الجديد في هذه النسخة
- **أداء**: Lite mode افتراضي على الأندرويد (بدون blur/animations)، الخطوط ملفات خارجية، وإيقاف كل المؤقتات والرسم والقياسات والتحديثات أثناء إخفاء الـ overlay، ونافذة الـ overlay تبقى مرفقة (1×1 بكسل) فيصبح الإظهار تحديث تخطيط بدل إنشاء نافذة.
- **النوافذ**: تظهر في منتصف الشاشة بعرض ضيّق ومحتوى مضغوط. إعداد جديد: *Card content transparency* (الافتراضي 0% = معتم).
- **المواقع**: الطقس والصلاة يدعمان: تلقائي (موقع الجهاز ثم IP بإجماع 3 مزوّدين)، أو بحث عن أي مدينة، أو اختيار دولة. لتفعيل موقع الجهاز اضغط **Allow location** في شاشة التطبيق (الصناديق بدون GPS/شبكة موقع ترجع للـ IP). موقع الصلاة يتبع الطقس افتراضياً ويمكن فصله.

## تحديث الأداء والواجهة (النسخة الأخيرة)
- **قراءة الرام والمعالج**: كل 4 ثوانٍ (2 ثانية فقط والنافذة مفتوحة)، تعمل في خيط خلفي وتُرجع آخر قياس فوراً فلا توقف الواجهة، وتُحدَّث الأرقام التي تغيّرت فقط. الحرارة مخزّنة مؤقتاً (8 ثوانٍ)، و`dumpsys` لا يُستدعى أكثر من مرة كل 20 ثانية (5 دقائق إن فشل).
- **الساعة**: تُحدَّث مرة في الدقيقة (كل ثانية فقط لو الساعة الأنالوج ظاهرة). قائمة التطبيقات والحرارة والتنظيف الآن غير متزامنة.
- **كووورة**: لا يُجلب إلا عند فتح البطاقة أو عند إظهار البطاقات لو مرّ أكثر من 15 دقيقة.
- **Smooth mode (high frame rate)**: يعزل كل بطاقة في طبقة رسم، ويطلب من النظام الإبقاء على معدل تحديث الشاشة الحالي. (لا يغيّر دقة/تردد HDMI.)
- **البحث عن مدينة**: يستخدم كيبورد الجهاز. اضغط OK على خانة البحث لفتحه، اكتب، ثم Enter/Search على الكيبورد.
- **سبب عرض النوافذ العريض**: دوال CSS مثل `min()` غير مدعومة في WebView القديم؛ استُبدلت بقيم ثابتة.

## StandBy: أشكال جديدة + StandBy تلقائي
- **19 شكل ساعة** على خلفية سوداء AMOLED (أنالوج: كلاسيك/أرقام/Minimal/رومانية/عربية/Neon/نقاط/Ring — رقمي: Digital/Thin/Stack/Outline/Gradient/أرقام عربية/نص عربي «الساعة العاشرة والنصف»/نص إنجليزي/تاريخ+وقت). تتغير من شريط الخيارات أثناء الاستاند باي (Style) مع لون الساعة. الساعة تُزاح بضعة بكسلات كل دقيقة لحماية الشاشة.
- **StandBy تلقائي**: الإعدادات ▸ AUTO STANDBY: اختر المدة (1 دقيقة للتجربة، 1/2/3/4/6/8/12 ساعة). العدّاد يبدأ من آخر ضغطة ريموت (أي مفتاح في أي تطبيق) ويُعاد من الصفر مع كل ضغطة. عند التفعيل: يوقف التشغيل مؤقتاً، ويُطفئ الواي فاي (اختياري)، ثم يعرض الاستاند باي. أي مفتاح أو HOME أو BACK يخرج منه، ثم تظهر رسالة «هل تريد إعادة تشغيل الواي فاي؟ نعم / لاحقًا».
- **الواي فاي**: التطبيق يستهدف API 28 لأن أندرويد 10+ يمنع التطبيقات الحديثة من تغيير الواي فاي؛ على أندرويد 9 يعمل مباشرة، وعلى 10–14 يجب أن يعمل بهذه الطريقة، وإن فشل يجرّب `su` (للصناديق المروّتة). لم يُجرَّب على جهاز فعلي. إن لم يتحكم في الواي فاي ستعمل بقية ميزات الاستاند باي بدون فصله.
- **تحريك البطاقات**: OK مطوّل = تدخل وضع التحريك ويبقى حتى تضغط OK مرة أخرى (أو Back). الأسهم تحرّك والبطاقة لا تُفلت ولو بقيت ضاغطاً.

## شريط اختصارات التطبيقات + إطار التحديد + القنوات الصوتية
- **اختصارات التطبيقات**: الإعدادات ▸ APP SHORTCUTS (مغلقة افتراضياً). عند التفعيل يظهر زر **+** أسفل يمين الشاشة؛ يعرض كل تطبيقات الجهاز وتختار حتى **5** (علامة ✓ = مضاف، اضغط عليه ثانية لإزالته). 3 أشكال: Glass (زجاجي بإطار ذهبي)، Neon (دوائر مع تحديد بشكل عضوي متوهج)، Color tiles (مربعات ملونة لامعة). OK مطوّلاً على الشريط = تحريكه كله، ويُحفظ مكانه.
- **إطار التحديد**: بقي حدوده مدوّرة بالكامل مثل المعاينة (WebView القديم كان يرسم `outline` مستطيلاً؛ استُبدل بإطار `box-shadow` يتبع شكل البطاقة).
- **القنوات الصوتية**: بجانب كل قناة ناقلة ذات رقم تظهر بطاقة بأيقونة مايك باسم «صوتية رقم N» (مثلاً beIN Sports Mena 5 ← صوتية رقم 5). تُحذف الأرقام المكررة.

## استقرار الأداء (النسخة الأخيرة)
- **لا blur في الـ overlay أبداً**: الـ overlay نافذة منفصلة فوق النظام فلا يوجد خلف الصفحة ما يمكن تغبيشه، لذلك كان الـ blur تكلفة بلا فائدة. تغيّر الألوان لحظي، والحركات انتقال/تلاشٍ فقط. إعداد **Animations**: Off / Fast / Normal (الافتراضي Fast).
- **حارس ذاتي**: (1) إن توقف خيط الواجهة في التطبيق أو تباطأت إطارات الصفحة أثناء ظهور البطاقات، يعاد تشغيل الـ WebView تلقائياً (الإعدادات محفوظة). (2) بعد أي جلسة أطول من 3 دقائق، يُنشأ WebView جديد في الخلفية بعد إخفاء البطاقات بـ 15 ثانية ليكون الفتح التالي سريعاً كأنه أول مرة.
- بطاقة المباريات تنتقل بين المباريات كل **30 ثانية**، ولا تتبدل عند أي إعادة رسم.
- القنوات الصوتية: لقنوات **beIN Sports Mena N** فقط («صوتية رقم N»، بنفس التحديد الأبيض)، وقناة **stc tv** تظهر «صوتية الإيطالية».
- ألوان خلفية جديدة: Black / Charcoal / Dark Gray / Gray / Light Gray.

## الاسم والأيقونة (AppleMe / تفحني)
- الاسم: **AppleMe** (وعلى جهاز لغته العربية يظهر **تفحني**). الأيقونة هي الصورة التي أرسلتها: مربع مدوّر بحواف شفافة. وضعتها كأيقونة تكيّفية بخلفية شفافة داخل المنطقة الآمنة، فتظهر بإطارها المدوّر على أي لانشر/قناع (دائري أو مربع مدوّر)، وبنسخة PNG عادية للأجهزة القديمة، وبانر خاص لأندرويد TV. الـ `applicationId` لم يتغيّر (`com.tvoshome.app`) فيُحدّث فوق النسخة المثبّتة بدون فقد الإعدادات.

## المباريات والتحميل في الخلفية
- جلب كووورة وتحليلها صار **نيتف بالكامل في خيط خلفي بأولوية منخفضة** (لا WebView ثانٍ): أول مرة بعد 60 ثانية من تشغيل الخدمة ثم كل 30 دقيقة، ولا يعمل أبداً أثناء فتح البطاقات. النتيجة تُحفظ جاهزة على القرص، فعند فتح التطبيق تظهر المباريات فوراً بدون أي شبكة. زر «تحديث الآن» يفرض التحديث (وإن فشل يجرّب الطريقة القديمة بـ WebView).
- الطقس لا يُجلب إلا بعد 25 ثانية من تشغيل الصفحة، ولا يعيد رسم الواجهة كلها (فقط البطاقات/النافذة المفتوحة).
- إشعار المباراة صار يعرض: المباراة والوقت والتاريخ و**«شاهد على:»** مع كل القنوات (والقنوات الصوتية).

## ألوان البطاقات والشفافية + إصلاح الأيقونة
- **Card colour**: اللون المختار يلوّن **البطاقات** وقوائمها فقط (لا يغطي الشاشة). **Card transparency**: افتراضياً شفافة (45%) في الوضع الكامل، وصلبة (0%) في Lite. **Content transparency**: القوائم المفتوحة من البطاقات، افتراضياً 0% في الوضعين. الألوان الفاتحة جداً (Light Gray) تبدّل لون النص لداكن.
- **الأيقونة**: الأيقونة التكيّفية صارت بخلفية بيضاء متدرّجة بنفس لون الصورة (#FEFEFE ← #EAEAEA) والصورة تملأ المنطقة الظاهرة كاملة، فلا يظهر فراغ أسود. على اللانشر الذي يقصّ دائرة تظهر دائرة بيضاء بدل مربع مدوّر لأن القناع من اللانشر.

## إخفاء شعار القناة (Channel logo cover)
- الإعدادات ▸ **CHANNEL LOGO COVER**: مفتاح تشغيل/إيقاف + اختيار (Connect / ساعة أنالوج / ساعة ديجتال) + تعديل المكان والحجم + إعادة الضبط.
- **بدون لقطات شاشة**: خدمة الإتاحة تقرأ نص الشاشة. عند ظهور `11258 V 30000` (معدل الرموز ±4) في أي تطبيق/قائمة يظهر الغطاء أعلى اليمين. يختفي عند ظهور تردد آخر أو تغيير التطبيق أو فتح البطاقات.
- الفحص مُخفَّف: لا يعمل إلا بعد تغيّر في الشاشة وبحد أقصى مرة كل ~0.7 ث.
- **التعديل**: ضغطة طويلة على الغطاء (لمس/ماوس) أو زر Edit في الإعدادات. بالريموت: الأسهم تحرك، OK يبدّل بين تحريك/تكبير، Back حفظ وخروج. كل تغيير يُحفظ فوراً.
- بعد تحديث التطبيق أوقف خدمة الإتاحة وشغّلها مرة واحدة (صلاحية قراءة محتوى الشاشة).
- لا يعمل إن كان التطبيق يرسم النص كصورة/OpenGL بدون عناصر نصية قابلة للقراءة.
- v4: يفحص كل النوافذ (شريط المعلومات غالباً نافذة منفصلة)، يحفظ مكان نص التردد، ويخفي الغطاء فقط إذا ظهر تردد آخر في نفس المكان. زر **Test** في الإعدادات يعرض ما يقرأه التطبيق من الشاشة.
- v6: الساعتان (أنالوج/ديجتال) بشكل بطاقة بيضاء بالتاريخ الميلادي والهجري. خيار **MATCH INFO CARD**: يقرأ سطر المباراة من الانفو (أي لغة، ويُعتمد فقط مع وجود سطر تردد)، يترجم الأسماء ويجلب الشعارات من Wikidata (بدون مفتاح)، يطابقها مع بيانات كووورة للقناة/المعلق، ويعرض بطاقة 10 ثوانٍ (مخزنة بالذاكرة لنفس المباراة). موضعها قابل للتعديل (Edit) ومحفوظ، وزر Test للتشخيص.
- v7: تحليل سطر المباراة أذكى: يحذف الأوقات و Live/مباشر/ישיר وغيرها بأي لغة، ثم يتحقق من Wikidata أن الاسمين نادٍ أو منتخب كرة قدم قبل عرض البطاقة (ما ليس فريقين يُتجاهل ولا يُعاد البحث عنه).
